# Project 2 - Data Classification Using AI

## Project Overview

This project demonstrates a basic Artificial Intelligence classification model using supervised learning.

The model is trained using the Iris dataset and learns to classify flowers into different categories based on their measurements.

## Objective

The main objective of this project is to understand the basic machine learning classification process:

* Load a dataset
* Understand the data
* Split the data into training and testing sets
* Train a classification model
* Make predictions
* Check the model accuracy

## Dataset

This project uses the built-in Iris dataset from Scikit-learn.

The dataset contains four input features:

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width

The model predicts one of three flower classes:

* Setosa
* Versicolor
* Virginica

## Algorithm Used

### Decision Tree Classifier

A Decision Tree is a supervised machine learning algorithm.

It learns decision rules from the training data and uses those rules to classify new data.

## How to Run

### Step 1: Install Python

Make sure Python is installed on your computer.

### Step 2: Open the project in VS Code

Open the project folder:

```text

```

### Step 3: Install the required library

Open the VS Code terminal and run:

```bash
pip install -r requirements.txt
```

### Step 4: Run the program

Run:

```bash
python classification.py
```
